# SONARA

Plataforma de streaming musical independiente. Desarrollo en Preview; no publicar a producción sin autorización expresa.

## Stack previsto
- Next.js + TypeScript
- Supabase Auth y PostgreSQL
- Reproducción de audio con archivos y enlaces autorizados

## Configuración
Copia `.env.example` a `.env.local` y completa las variables desde el proyecto Supabase. Nunca subas secretos ni archivos `.env.local` al repositorio.
